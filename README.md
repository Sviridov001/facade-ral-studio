# Фасад · RAL Studio

Браузерное приложение для подбора цветов отделки фасада: 103 приблизительных экранных цвета RAL, четыре зоны, два ракурса, готовые сочетания и ручной редактор масок.

[Открыть приложение](https://facade-ral-studio.lathes-will-1i.chatgpt.site) · [Краткая справка](dist/help.html) · [План развития](ROADMAP.md)

## Фотографии для локального запуска

В GitHub опубликован код без двух фотографий фасадов. Для текущего демонстрационного проекта нужны исходные файлы `dist/assets/view-0.jpg` и `dist/assets/view-1.jpg` (2048 × 1143). Скопируйте их из вашего ранее скачанного локального пакета в те же пути. В репозитории уже есть маски и геометрия для этих конкретных фото. Пока фотографии не добавлены, приложение покажет ошибку загрузки. Замена их произвольными фото не поддерживается: текущие маски будут неверны.

## Запуск на Windows

Нужен Python 3. Из папки проекта выполните:

```powershell
py -m http.server 8080 --bind 127.0.0.1 --directory dist
```

Откройте http://localhost:8080. Остановка сервера — Ctrl+C. Двойной щелчок по `index.html` не подходит: приложение загружает JSON через `fetch`, поэтому нужен HTTP-сервер.

На macOS/Linux замените `py` на `python3`. Сборка, npm и внешние библиотеки для работы страницы не нужны. Можно разместить содержимое `dist/` на статическом хостинге.

## Возможности

- Окрашивание четырёх зон с сохранением яркости и теней исходного фото.
- Поиск RAL, осветление, готовые палитры и приближённый автоподбор гармоний.
- Два ракурса, сравнение до/после, PNG и JSON-спецификация цветов.
- Увеличение до 800%, контуры с перетаскиванием вершин, вырезы и кисть.
- До 30 сохранённых палитр и автоматическое локальное сохранение разметки.
- Экспорт/импорт JSON-разметки двух встроенных ракурсов.

## Проверки

Нужен Node.js. Из корня проекта:

```text
node --check dist/app.js
node --check dist/editor.js
node check.cjs
node editor-check.cjs
```

Проверки используют имитацию DOM/Canvas: они проверяют алгоритмы, сохранение, отмену и статические ссылки, но не заменяют проверку интерфейса в браузере.

Для повторной генерации исходных масок нужны Python, Pillow, NumPy и SciPy:

```text
python -m pip install -r requirements-masks.txt
python geometry_masks.py
```

Генератор перезаписывает маски и геометрию в `dist/assets/`, диагностические изображения кладёт в `qa/`. Координаты привязаны к двум встроенным фото. Старый `prepare_assets.py` в служебном исходном проекте заменён этим генератором и не входит в переносимый пакет.

## Формат данных и ограничения

Красный канал `mask-N.png` хранит целочисленные метки: 0 — защита, 1–4 — зоны отделки. Это служебная карта меток, не обычная чёрно-белая маска. `occlusion-N.png` защищает перекрывающую растительность. `geometry.json` содержит полигоны с полями `zone`, `name`, `points` в пикселях исходного фото.

Хранение — только `localStorage` текущего браузера и адреса. Ключи: `facade-ral-v1`, `facade-geometry-v2`. Скачанная спецификация описывает текущую палитру, а файл разметки содержит контуры и мазки обоих ракурсов. Очистка данных сайта удаляет локальные сохранения.

Текущая версия привязана к одному ЖК, двум фото и четырём зонам. Произвольные фото, PNG-маски из Archicad и переносимые файлы проектов пока не поддерживаются. Приближённый цвет на экране не является физическим образцом RAL; светотеневое перекрашивание не пересчитывает отражения и цветные переотражения. Оставшиеся ошибки масок исправляются редактором.
